RECRUIT 採用情報

札幌看護医療専門学校では教員・非常勤講師を募集しています。
学校の運営や教育現場に興味のある方は、ご応募下さい。

募集職種

  1. 看護学科専任教員（契約職員・正職員）
  2. 歯科衛生士学科専任教員（契約職員・正職員）
  3. 臨床工学技士学科専任教員（契約職員・正職員）
  4. 視能訓練士学科専任教員（契約職員・正職員）

応募資格

（全学科共通）次世代の医療を支える人材を育成する熱意のある方。本校が推進しているICT教育に興味と理解のある方。

  1. （看護学科）看護師の資格を有し、5年以上の実務経験を持つ方。
  2. （歯科衛生士学科）歯科衛生士の資格を有し、5年以上の実務経験を持つ方。
  3. （臨床工学技士学科）臨床工学技士の資格を有し、5年以上の実務経験を持つ方。
  4. （視能訓練士学科）視能訓練士の資格を有し、5年以上の実務経験を持つ方。

採用人数

若干名

勤務時間等

①②③④（専任教員）
8:40～17:40（8:20～17:20等のシフトパターン有）

【休日】
1.土・日・祝日　2.年末年始　3.夏期休暇　他

  • シフト制（オープンキャンパス等の対応で土日祝勤務の場合は他の勤務日と振り替え）

【給与】
当校規定により、能力・経験等を考慮し、個別に決定いたします。

応募方法・書類提出先

  • 書留郵便とし、封筒には「教員応募書類在中」とご記入下さい。
  • ご提出いただいた書類は、本校の規定に従い適切に管理し、採用選考の目的以外には使用いたしません。
